# PayQuick V2 Development Roadmap

## Stage 0: Foundation
Repository structure, frontend shell, API, database, shared constants, and contract boundary.

## Stage 1: Wallet and Merchant Identity
- Connect wallet
- Verify wallet ownership
- Create merchant profile
- Load merchant account
- Enforce Arc Testnet

## Stage 2: Invoices
- Create invoice
- Store invoice
- Generate checkout link
- Invoice status
- Invoice expiration

## Stage 3: Checkout and Payments
- Customer checkout
- Wallet connection
- USDC payment
- Transaction submission
- Transaction receipt

## Stage 4: Payment Verification
- Blockchain event monitoring
- Transaction verification
- Invoice settlement
- Instant status updates
- Shared payment scan

## Stage 5: Customers and History
- Customer records
- Payment history
- Invoice history
- Receipts

## Stage 6: Notifications
- Payment received
- Invoice paid
- Invoice expired
- Merchant notifications

## Stage 7: Merchant Tools
- Dashboard analytics
- Customer management
- Revenue statistics
- Payment search and filtering
- Merchant settings

## Stage 8: Reliability and Security
- Validation
- Authentication
- Authorization
- Rate limiting
- Error handling
- Automated tests
- Payment monitoring
- Audit logging

## Stage 9: Mainnet Readiness
- Mainnet configuration
- Production contracts
- Production infrastructure
- Security review
- Monitoring
- Backup and recovery
- Final payment testing

Mainnet development must not begin until the Testnet system is stable.
