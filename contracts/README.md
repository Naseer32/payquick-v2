# PayQuick Contracts

This directory contains PayQuick smart-contract ABIs, deployment information, and contract-related documentation.

## Environments

Development is Arc Testnet only.

Mainnet contract addresses must not be added until the Mainnet readiness stage.

## Payment contract

The payment contract will be responsible for recording the blockchain events that the PayQuick payment service verifies.

Contract ABIs will be stored in this directory rather than inside the frontend application.
